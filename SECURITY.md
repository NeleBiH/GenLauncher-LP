# Security Policy

## Supported versions

Only the latest release of GenLauncher-LP receives fixes. Update with the
**UPDATE** button in the launcher or with `setup_genlauncher_LP.sh`.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report them privately through GitHub:
[Security → Report a vulnerability](https://github.com/NeleBiH/GenLauncher-LP/security/advisories/new).

Useful details:

- what an attacker can do (for example: write files outside the mod folder
  through a crafted archive or catalog entry),
- steps or a sample file to reproduce it,
- the launcher version (shown under the About button).

You should get a reply within a week. Once a fix is released, the report can
be made public with credit to you, if you want.

## Scope

GenLauncher-LP downloads mods listed in a community catalog it does not
control. Malicious content inside a mod itself should be reported to that
mod's authors; issues in how the launcher downloads, extracts or links files
are in scope here.
